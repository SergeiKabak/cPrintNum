## 2. Что нужно до начала

| Требование | Обязательно? |
| ---------- | ------------ |
| **Windows 7 SP1 x64** (или 10/11) | ✅ Да |
| Принтер, установленный в Windows | ✅ Да |
| Chromium-браузер (Chrome / Яндекс / Edge / Opera) | ✅ Да |
| Python, Node.js, WebView2 | ❌ **Нет** — не нужны |

### Windows 7: важное обновление

Приложению требуется обновление **KB2533623** (обычно уже установлено).
Если PrintNum не запускается — установите его с сайта Microsoft.

Также для Windows 7 может потребоваться **SP1** (Service Pack 1).

## 3. Установка приложения

Приложение **не требует установки** — это один файл.

1. Скопируйте `printnum.exe` в удобную папку, например:
   ```
   C:\PrintNum\printnum.exe
   ```

   > ⚠️ Не запускайте из `Загрузок` или с сетевого диска — используйте
   > постоянную папку.

2. Запустите **двойным кликом**.

3. Откроется окно **«PrintNum — Печать ячеек»**.

4. Если Windows SmartScreen предупреждает о неизвестном издателе
   (на Windows 7 — «Запустить всё равно»), разрешите запуск.

### Проверка, что приложение работает

В окне приложения:
- кнопка должна быть **красной** со словом **«Остановить»** — это значит,
  приложение активно и готово печатать;
- внизу справа не должно быть надписи **«Принтер НЕДОСТУПЕН»**.

## 4. Установка расширения

### Способ А — из файла (проще)

1. Скачайте/откройте **Chrome Web Store** и найдите
   **«PrintNum — Печать Ячеек (Ozon)»**, нажмите **«Установить»**.

   *Если магазин недоступен* — используйте способ Б.

### Способ Б — распакованное расширение

1. Откройте браузер и перейдите на:
   ```
   chrome://extensions
   ```
2. Включите **«Режим разработчика»** (переключатель справа сверху).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `extension\chromium\` из архива.
5. Расширение **PrintNum** появится в списке.

### После установки

**Перезагрузите все открытые вкладки Ozon** (F5 или Ctrl+F5).

При первой отправке номера браузер может спросить разрешение на обмен
данными с **localhost** — нажмите **«Разрешить»**. Больше не спросит.

## 5. Настройка приложения

1. В окне PrintNum нажмите **⚙ (шестерёнка)** справа сверху.
2. Заполните:

   | Параметр | Что делать |
   | -------- | ---------- |
   | **Принтер** | Выберите ваш принтер из списка |
   | **Этикетка (mm)** | Выберите размер, например `30*20` |
   | **Показывать ID** | Показывать вторую часть номера (`-47`) |
   | **Подчёркивание** | Вместо точки — подчёркивание |
   | **Гибридный формат** | Режим с порогом (см. ниже) |
   | **Начиная с номера** | Порог для гибридного формата |

3. **Важно:** размер бумаги в драйвере принтера должен **совпадать**
   с размером в PrintNum. Иначе этикетка напечатается пустой или сместится.

   Как задать размер в драйвере:
   - **Панель управления → Устройства и принтеры**
   - Правый клик на принтере → **Свойства принтера**
   - Вкладка **Параметры** → задайте размер этикетки вручную

Настройки сохраняются автоматически и восстанавливаются при следующем запуске.

## 6. Проверка работы

1. Убедитесь, что приложение PrintNum запущено (кнопка красная).
2. Откройте страницу Ozon, где печатаются номера ячеек.
3. Введите или отсканируйте номер ячейки.
4. Этикетка должна напечататься автоматически.

### Проверка без Ozon (через командную строку)

Откройте **cmd** и выполните:
```bat
curl http://127.0.0.1:5000/
```
Если ответ `{"status":true}` — приложение отвечает.

Отправить тестовую печать:
```bat
curl -X POST http://127.0.0.1:5000/print-number ^
  -H "Content-Type: application/json" -d "{\"text\":\"123-47\"}"
```

## 7. Печать штрихкодов (Code128)

В popup расширения (иконка PrintNum на панели браузера) есть блок
**«Штрихкод Code128»**.

1. Введите текст ШК (например, `ii18725308927`).
2. Увидите предпросмотр с полосками и текстом под ними.
3. Нажмите:
   - **«Печать через PrintNum»** — печать на термопринтер через приложение;
   - **«Печать из браузера»** — печать из браузера (обычный принтер).

Кнопка-шестерёнка в блоке ШК открывает настройки:
- **высота полосок** (мм), по умолчанию 10;
- **ширина модуля** (мм), по умолчанию 0.25.

## 8. Автозапуск (рекомендуется)

Чтобы PrintNum запускался вместе с Windows:

1. Нажмите **Пуск** → введите `shell:startup` → Enter.
2. Откроется папка «Автозагрузка».
3. Создайте **ярлык** на `printnum.exe` в этой папке
   (правый клик → Создать → Ярлык).

Теперь приложение будет стартовать автоматически, и расширению всегда
будет с кем работать.

## 9. Дополнительно: native messaging

По умолчанию расширение общается с приложением по HTTP (порт 5000).
Альтернатива — **native messaging** (без открытого порта).

### Настройка

1. Узнайте **ID расширения**: `chrome://extensions` → карточка PrintNum → **ID**.
2. Откройте **cmd** от имени пользователя и выполните:
   ```bat
   cd /d C:\PrintNum
   install-native-host.bat "C:\PrintNum\printnum.exe" "<ID-расширения>"
   ```
3. Перезапустите браузер.

После этого popup будет использовать native messaging, а при его
недоступности — автоматически откатится на HTTP.

> Подробнее — в `docs\native-messaging.md`.

## 10. Если что-то не работает

| Симптом | Решение |
| ------- | ------- |
| Приложение не запускается на Win7 | Установите KB2533623 и Service Pack 1 |
| Номер не печатается | Проверьте: приложение запущено, расширение включено, вкладка Ozon перезагружена, принтер выбран |
| Этикетка пустая / смещена | Размер бумаги в драйвере ≠ размер в PrintNum |
| «Принтер НЕДОСТУПЕН» | Принтер offline / нет бумаги / не выбран в настройках |
| Браузер не видит приложение | Порт 5000 занят другим ПО; проверьте `curl http://127.0.0.1:5000/` |
| Расширение не появилось | Проверьте, что папка `extension\chromium\` загружена целиком |
| `printnum.exe` не стартует | Скачайте заново — файл мог повредиться при копировании |

### Сбор логов

Если нужно сообщить о проблеме — запустите приложение из командной строки,
чтобы увидеть сообщения:
```bat
cd /d C:\PrintNum
printnum.exe --dry-run
```
(режим `--dry-run` печатает разбор номера без реальной печати).

## 11. Удаление

1. Закройте PrintNum.
2. Удалите папку `C:\PrintNum\`.
3. Удалите ярлык из автозагрузки (если создавали).
4. Удалите расширение: `chrome://extensions` → PrintNum → **Удалить**.
5. Настройки удаляются вместе с папкой данных:
   ```
   %APPDATA%\PrintNum\
   ```
6. Если настраивали native messaging — удалите ключ реестра:
   ```bat
   reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\ru.printnum.host" /f
   ```
