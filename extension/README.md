# 🌐 PrintNum Extension

Браузерное расширение для автоматизации работы сотрудников ПВЗ Ozon.

Расширение интегрируется с сайтом `turbo-pvz.ozon.ru` и взаимодействует приложением PrintNum для печати номеров ячеек, а также автоматизирует ряд рутинных операций через QR-коды, автоскрипты и дополнительные инструменты интерфейса.

# Использование

[(Вернуться к началу)](#-printnum-extension)

## QR-команды

> ℹ️ Перед использованием QR-кодов их можно распечатать для удобства работы.  
> Файл с QR-кодами можно найти через иконку расширения.

### Выдать заказ (без пакета / M / L)

> ℹ️ Данный скрипт работает только с предоплаченными заказами.

> ℹ️ Если во время выполенения будет заказ, где требуется оплата, либо ануляция, он автоматически остановиться.

Раздел, где сработает QR-код:

```text
Выдача заказов → Открытая карточка для выдачи
```

Выполняет следующие действия:

1. Продолжить
2. Выбор пакета
3. Выдать
4. На главную

---

### Выдать всё (без пакета / M / L)

> ℹ️ Данный скрипт работает только с предоплаченными заказами и закрывает их поочередно один за другим.

> ℹ️ Если во время выполенения будет заказ, где требуется оплата, либо ануляция, он автоматически остановиться.

Раздел, где сработает QR-код:

```text
Выдача заказов
```

Выполняет следующие действия:

1. К выдаче
2. Продолжить
3. Выбор пакета
4. Выдать
5. На главную

---

### Оплатить заказ (без пакета / M / L)

> ℹ️ Данный скрипт работает только с оплаченными заказами.

> ℹ️ Если во время выполенения будет заказ, где НЕ требуется оплата, либо ануляция, он автоматически остановиться.

Раздел, где сработает QR-код:

```text
Выдача заказов → Открытая карточка для выдачи
```

Выполняет следующие действия:

1. Продолжить
2. Выбор пакета
3. Провести оплату
4. На главную

Если оплата не прошла и появилась кнопка:

```text
Попробовать ещё
```

повторное сканирование QR-кода продолжит выполнение сценария.

---

### Отказ от товара

> ℹ️ Скрипт работает стабильно и без ошибок. Однако при аннулировании товара обязательно проверяйте результат визуально: из-за слабого интернет-соединения работа скрипта может прерваться.

Раздел, где сработает QR-код:

```text
Выдача заказов → Открытая карточка для выдачи
```

Как использовать:

1. Отсканируйте товар.
2. В течение 3 секунд отсканируйте QR-код причины возврата.

Выполняет следующие действия:

1. Проверить
2. На проверке
3. К выдаче
4. Изменил решение о покупке/Товар не подошёл

---

### С рекомендацией

Раздел, где сработает QR-код:

```text
Приёмка
```

Выполняет следующие действия:
Автоматически переключает тумблер (флажок / режим)

```text
С рекомендацией
```

## Автоскрипты

### Упаковки Ozon нет в наличии

Раздел, где скрипт автоматически активируется:

```text
Отправка → Отправка перевозок → Прямой/Возвратный поток
```

Как использовать:

1. Выберите возврат для упаковки.
2. Отсканируйте товар.
3. Автоматически будет выбрано:
   - «Упаковки Ozon нет в наличии».
4. Отсканируйте новый штрихкод.
5. При появлении кнопки «Завершить» они нажмётся автоматически.
6. Повторно отсканируйте товар с новым штрихкодом.
7. Товар будет добавлен в перевозку.

### Перенести тарники в перевозку

Раздел, где скрипт автоматически активируется:

```text
Отправка → Отправка перевозок → Прямой/Возвратный поток
```

Как работает:

> ℹ️ Все тарники автоматически переносятся в любую открытую перевозку

# API взаимодействия

[(Вернуться к началу)](#-printnum-extension)

Базовый URL:

```text
http://127.0.0.1:5000
```

| Метод | Endpoint      | Назначение           |
| ----- | ------------- | -------------------- |
| GET   | /             | Проверка доступности |
| POST  | /print-number | Печать номера        |

Пример:

```javascript
await fetch("http://127.0.0.1:5000/print-number", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    number: "123-456",
  }),
});
```

## Эмулятор сканера ШК (только для разработки)

Физический сканер штрихкодов работает как HID-клавиатура: очень быстро «набирает»
символы штрихкода и завершает ввод клавишей Enter. Чтобы проверять обработку
сканирования **без реального сканера**, в dev-сборке доступен эмулятор.

### Как запустить

1. Установите зависимости (только в первый раз):

   ```bash
   npm install
   ```

   > Без `node_modules` команда `npm run dev` выдаст `wxt: command not found`.

2. Соберите расширение в режиме разработки:

   ```bash
   npm run dev
   ```

   WXT соберёт расширение в `extension/output/chrome-mv3` и откроет Chrome.

3. Если браузер не открылся сам — загрузите распакованное расширение
   из `output/chrome-mv3` в браузер
   (`chrome://extensions` → «Загрузить распакованное»).
4. Откройте страницу Ozon и DevTools (F12).
5. **Переключите контекст Console на `PrintNum`** — в выпадающем списке рядом
   с `top` (content script живёт в изолированном мире, иначе вы получите
   `PrintNumScanner is not defined`).
6. В консоли вызовите:

   ```js
   // одиночное сканирование
   PrintNumScanner.simulate("123-47");

   // серия сканирований с паузами между ними
   PrintNumScanner.simulateSequence(["123-47", "500-47", "КГТ-1"], 1500);
   ```

Эмулятор генерирует реальные события `keydown` на `window` — точно так же,
как это делает сканер. Поэтому проверяется вся боевая цепочка:
`utils/listener.ts` → content script → отправка номера.

В консоли появится:

```
[PrintNum:scanner] отсканировано: "123-47"
[PrintNum:scanner] обработка номера: "123-47"
[PrintNum:scanner] номер "123-47" отправлен в PrintNum
```

### Параметры

| Функция                                                | Описание                                          |
| ------------------------------------------------------ | ------------------------------------------------- |
| `simulate(value, charDelay = 15)`                       | Симулирует сканирование одного ШК                 |
| `simulateSequence(values, delayMs = 1500, charDelay = 15)` | Серия сканирований с паузой между ними |
| `onSimulatedScan(callback)`                             | Подписка на результат симулированного сканирования |

### Важно

- Эмулятор **доступен только в dev-режиме** (`npm run dev`). В production-сборке
  (`npm run build`) код эмулятора полностью вырезается из бандла — в рабочем
  расширении его нет.
- Для полного сквозного теста (сканирование → печать) запустите PrintNum в режиме
  эмуляции печати (`printnum.exe --dry-run`). Тогда номер не уйдёт на принтер,
  а разбор этикетки будет выведен в терминал приложения (на Windows — ещё и
  сохранён как превью).
- Порт приложения по умолчанию — `5000`. Если он изменён (`PRINTNUM_PORT` в
  приложении), укажите тот же порт в `extension/.env` (`VITE_PRINTNUM_PORT`)
  и пересоберите расширение.

> Внутренний модуль: [`src/utils/scannerSimulator.ts`](./src/utils/scannerSimulator.ts).
>
> Полная инструкция по эмуляции (включая эмуляцию печати) — в
> [`docs/emulation-testing.md`](../docs/emulation-testing.md).
