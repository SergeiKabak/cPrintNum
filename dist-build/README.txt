========================================================================
  PrintNum — исходники для сборки на Windows 10 (под Windows 7)
========================================================================

ЧТО ЭТО
-------
Архив с исходным кодом PrintNum. Вы соберёте приложение и расширение
на Windows 10, а готовый .exe будет работать на Windows 7 SP1 x64.

КАК СОБРАТЬ (кратко)
--------------------
1. Установите: Rust, MSVC Build Tools ("Разработка классических
   приложений на C++"), Node.js 18+, Git.
   Подробно — в BUILD-WINDOWS-10-FOR-WIN7.md

2. Соберите приложение:
       cd src-printnum
       build-windows.bat

3. Соберите расширение:
       cd extension
       npm install
       npm run build

4. Создайте готовый архив целиком:
       cd dist-windows
       build-release.bat

   Результат: PrintNum-win7-x64-v3.0.0.zip в корне проекта.

ПОДРОБНАЯ ИНСТРУКЦИЯ
--------------------
Смотрите файл:  BUILD-WINDOWS-10-FOR-WIN7.md

ЧТО ВНУТРИ
----------
  src-printnum\        приложение (Rust + Slint)
  extension\           браузерное расширение (Preact + WXT)
  dist-windows\        сборка готового архива для пользователя
  docs\                документация
  Makefile             сборка через make (если установлен)
  BUILD-WINDOWS-10-FOR-WIN7.md   эта инструкция

ВАЖНО
-----
- Путь распаковки НЕ должен содержать пробелов и кириллицы.
  Правильно: C:\PrintNum-src\
- Первая сборка займёт 5-15 минут.
- Обязательно проверьте .exe на реальном Windows 7 перед раздачей.
- Требуется Windows 7 SP1 x64 + обновление KB2533623.

Особенности сборки под Windows 7 (уже настроены в проекте):
- статическая линковка CRT (+crt-static) — не нужен VC++ Redistributable;
- software-рендерер Slint — без OpenGL/Direct2D (совместимо с Win7).
