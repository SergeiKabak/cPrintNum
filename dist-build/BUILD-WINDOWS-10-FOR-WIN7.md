## 🚀 Самый быстрый путь

Если установлены Rust, MSVC Build Tools и Node.js (см. раздел 1),
то вся сборка делается **одной командой** из корня проекта:

```bat
BUILD.bat
```

Скрипт сам:
1. проверит инструменты;
2. соберёт `printnum.exe`;
3. соберёт расширение;
4. создаст готовый `PrintNum-win7-x64-v3.0.0.zip`.

Результат — в корне проекта. Дальше — раздел 6.

> При запуске без установленных инструментов `BUILD.bat` подскажет,
> что именно нужно установить.

Если хотите собирать пошагово или разобраться в деталях — читайте
разделы 1–5 ниже.

## 1. Что нужно установить

Установите по порядку.

### 1.1. Rust

1. Откройте **https://rustup.rs/**
2. Скачайте `rustup-init.exe` и запустите.
3. Нажмите **1** (default install).
4. Дождитесь окончания.
5. **Перезапустите командную строку** (важно!).

Проверка:
```bat
rustc --version
cargo --version
```

### 1.2. MSVC Build Tools (обязательно!)

Rust на Windows использует линкер Microsoft. Без него сборка упадёт.

1. Откройте **https://visualstudio.microsoft.com/downloads/**
2. Прокрутите до **«Tools for Visual Studio»**.
3. Скачайте **«Build Tools for Visual Studio»**.
4. Запустите установщик.
5. На вкладке **«Рабочие нагрузки»** отметьте:
   - ✅ **«Разработка классических приложений на C++»**
     (Desktop development with C++)
6. Нажмите **«Установить»** (займёт ~7 ГБ, это нормально).

### 1.3. Windows SDK

Обычно ставится вместе с Build Tools (см. 1.2, компонент по умолчанию).
Если нет — в установщике на вкладке **«Отдельные компоненты»** отметьте
**«Windows 10 SDK»**.

> ⚠️ Для сборки **под Windows 7** можно оставить Windows 10 SDK —
> версия SDK не влияет на целевую ОС. Совместимость определяется
> статической линковкой CRT (уже настроена в проекте).

### 1.4. Node.js (только для расширения)

1. Откройте **https://nodejs.org/**
2. Скачайте **LTS**-версию (18 или новее).
3. Установите (везде «Далее»).

Проверка:
```bat
node --version
npm --version
```

### 1.5. Git (для клонирования)

1. Откройте **https://git-scm.com/download/win**
2. Установите с настройками по умолчанию.

Проверка:
```bat
git --version
```

## 2. Проверка окружения

Откройте **новую** командную строку (`Win + R` → `cmd` → Enter) и выполните:

```bat
rustc --version
cargo --version
node --version
git --version
```

Все четыре команды должны вывести версии. Если что-то не найдено —
перезапустите компьютер и проверьте снова.

Добавьте целевой target (обычно уже есть):
```bat
rustup target add x86_64-pc-windows-msvc
```

## 3. Сборка приложения

### 3.1. Распакуйте архив

Распакуйте полученный архив, например в:
```
C:\PrintNum-src\
```

**Важно:** путь не должен содержать пробелов и кириллицы.
Правильно: `C:\PrintNum-src\`
Неправильно: `C:\Мои документы\PrintNum\`

### 3.2. Соберите приложение

```bat
cd C:\PrintNum-src\src-printnum
build-windows.bat
```

Скрипт выполнит:
```
cargo build --release --target x86_64-pc-windows-msvc
```

Первая сборка займёт **5–15 минут** (компилируется Slint и зависимости).
Последующие — быстрее.

### 3.3. Результат

```
C:\PrintNum-src\src-printnum\target\x86_64-pc-windows-msvc\release\printnum.exe
```

Это готовый portable `.exe` — работает без установки.

> ✅ Приложение настроено на **software-рендерер** Slint (без OpenGL/Direct2D),
> чтобы работать на Windows 7 без проблем с графикой.
> ✅ CRT слинкована статически (`+crt-static`) — **не нужен**
> Visual C++ Redistributable.

## 4. Сборка расширения

```bat
cd C:\PrintNum-src\extension
npm install
npm run build
npm run zip
```

Результат:
```
C:\PrintNum-src\extension\output\chrome-mv3\           (распакованное)
C:\PrintNum-src\extension\output\printnum-*-chrome.zip (zip)
```

`npm install` в первый раз займёт 1–3 минуты.

## 5. Готовый архив

Для автоматической сборки всего архива есть **один скрипт в корне проекта**:

```bat
cd C:\PrintNum-src
BUILD.bat
```

Он:
1. соберёт `printnum.exe`;
2. соберёт расширение;
3. сложит всё вместе;
4. создаст `PrintNum-win7-x64-v3.0.0.zip` в корне проекта.

### Состав архива

```
printnum.exe                  приложение
extension\chromium\           расширение (распакованное)
extension\printnum-chrome.zip расширение (zip)
native-host\                  native messaging (опционально)
INSTALL-WINDOWS-7.md          инструкция для пользователя
READ-ME-FIRST.txt             краткая памятка
docs\                         подробная документация
README.md                     описание проекта
```

## 6. Что делать с архивом

Скопируйте `PrintNum-win7-x64-v3.0.0.zip` на компьютер с Windows 7.
Пользователь следует `INSTALL-WINDOWS-7.md`:

1. Распаковать архив.
2. Положить `printnum.exe` в `C:\PrintNum\` и запустить.
3. Установить расширение из `extension\chromium\`.
4. Настроить принтер и размер этикетки.
5. Перезагрузить страницы Ozon.

## 7. Проверка на Windows 7

> ⚠️ **Обязательно проверьте** готовый `.exe` на реальном Windows 7
> (или виртуальной машине) перед раздачей пользователям.

### Требования к Windows 7

| Требование | Как проверить |
| ---------- | ------------- |
| **Service Pack 1** | Панель управления → Система → «Service Pack 1» |
| **x64 (64-бит)** | Там же → «Тип системы: 64-разрядная» |
| **KB2533623** | Установлено ли обновление (обычно уже есть) |

Если приложение не запускается — установите **KB2533623**:
- https://support.microsoft.com/help/2533623

### Как проверить

1. Скопируйте `printnum.exe` на Windows 7.
2. Запустите двойным кликом.
3. Должно открыться окно «PrintNum — Печать ячеек».

Если окно открылось — приложение совместимо.

**Проверка из командной строки** (видно ошибки, если есть):
```bat
cd /d C:\PrintNum
printnum.exe --dry-run
```

Если появилась строка `HTTP сервер запущен на http://127.0.0.1:5000`,
а окно открылось — всё работает.

## 8. Если что-то не работает

### Ошибка сборки: `link.exe not found`

Не установлены MSVC Build Tools. Вернитесь к шагу 1.2 и установите
компонент **«Разработка классических приложений на C++»**.

### Ошибка: `error: linker 'link.exe' not found`

То же самое — нет MSVC. После установки **перезапустите командную строку**.

### `cargo: command not found`

Не установлен Rust или не перезапущена консоль. Установите Rust (1.1) и
откройте **новую** командную строку.

### Ошибка про `cmake` или `nasm`

Некоторые зависимости могут требовать их. Установите:
- CMake: https://cmake.org/download/
- NASM: https://www.nasm.us/

Затем добавьте их в PATH и перезапустите консоль.

### Приложение не запускается на Windows 7

1. Проверьте, что стоит **SP1** и это **x64**.
2. Установите **KB2533623**.
3. Запустите из командной строки (`printnum.exe --dry-run`) — увидите
   причину ошибки.

Если ошибка связана с DLL — сообщите, какая DLL отсутствует.

### `npm run build` падает

1. Убедитесь, что Node.js 18+ (`node --version`).
2. Удалите `node_modules` и установите заново:
   ```bat
   cd C:\PrintNum-src\extension
   rmdir /s /q node_modules
   npm install
   ```
