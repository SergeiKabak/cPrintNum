# Публикация в Microsoft Edge Add-ons

Пошаговая инструкция и готовые тексты для карточки магазина.

## 0. Что уже готово

- `npm run pack:store` → `cPrintNum/dist/store/printnum-<версия>.zip`
  (`manifest.json` в корне архива, без sourcemap, ~90 КБ);
- `dist/store/store-logo-300.png` — логотип 300×300 для карточки;
- политика конфиденциальности: `docs/privacy.md`.

## 1. Аккаунт партнёра

1. Открыть <https://partner.microsoft.com/dashboard/microsoftedge/overview>.
2. Войти личным Microsoft-аккаунтом (можно завести новый для проекта).
3. Заполнить профиль разработчика (имя/компания, страна) — это проверяет
   поддержка, обычно 1–3 рабочих дня.
4. Бесплатно: Microsoft не берёт плату за публикацию в Edge Add-ons.

## 2. Создание расширения

1. Dashboard → **Microsoft Edge** → **Create new extension**.
2. **Package** → загрузить `dist/store/printnum-<версия>.zip`.
   Если валидатор ругается — читать текст ошибки: чаще всего это
   отсутствующая иконка 128×128 или `description` длиннее 132 символов.
3. Заполнить карточку (тексты ниже в §3).
4. **Notes for certification** — обязательно (см. §4): без объяснения, что
   расширение работает только вместе с локальной службой, проверяющий увидит
   «не работает» и отклонит.
5. Отправить. Срок проверки: обычно 1–7 рабочих дней, обновления — быстрее.

## 3. Тексты карточки (копировать как есть)

### Название

```
PrintNum — печать этикеток для ПВЗ
```

### Краткое описание (≤132 символов)

```
Печать ячеек и этикеток с QR для ПВЗ Ozon: автопечать, проверка должников. Нужна локальная служба PrintNum (Windows).
```

### Подробное описание (RU)

```
PrintNum — помощник оператора ПВЗ: печатает этикетки с номером ячейки и
QR-кодом отправления на обычном принтере этикеток (203 dpi, 43×25 мм).

Что умеет
• Печать ячейки в один клик: 163-1, 12, 5-3 — номер крупно, с контрольной
  клеткой и QR рядом.
• Автопечать: сканируешь отправление на выдаче — этикетка печатается сама.
• QR берётся из ответа Ozon, поэтому никогда не перепутается с чужим.
• Список должников: если клиент не оплатил заказ, при выдаче появляется
  красное предупреждение и кнопка выдачи блокируется.
• Предпросмотр: можно сохранять этикетки в BMP вместо печати.
• Горячая клавиша Ctrl+O — включить/выключить автопечать.

Как устроено
Расширение не печатает само: оно передаёт данные маленькой службе
printnum-win7.exe на этом же компьютере (127.0.0.1:5000), а та печатает на
принтере через драйвер Windows. Служба бесплатная, лежит в релизах:
https://github.com/SergeiKabak/cPrintNum/releases

Требования
• Windows 7 SP1 и новее (x64).
• Принтер этикеток, установленный в Windows.
• Ozon: turbo-pvz.ozon.ru (вкладка ПВЗ).

Приватность
Расширение не собирает статистику и ничего не отправляет наружу: данные идут
только на локальную службу. Политика: https://sergeikabak.github.io/cPrintNum/privacy.html

Исходный код: https://github.com/SergeiKabak/cPrintNum
```

### Подробное описание (EN, необязательно)

```
PrintNum helps Ozon pickup-point operators print shelf/cell labels with a QR
code on a thermal label printer.

• One-click cell label (e.g. 163-1) with large digits, checker mark and QR.
• Auto-print on scan during handover.
• QR is taken from the Ozon API response, so it always matches the parcel.
• Unpaid-client (debtor) list: shows a red warning and blocks the handover
  button for debtors.
• Preview mode writes BMP files instead of printing.
• Ctrl+O toggles auto-print.

The extension talks only to a local helper service (printnum-win7.exe,
127.0.0.1:5000) that prints through the Windows driver. No data is collected or
sent anywhere else.
```

### Категория

`Productivity` (или `Developer tools`, если хотите меньше вопросов).

### Язык

Русский (основной), английский (дополнительный).

## 4. Notes for certification (вставить в поле проверки)

```
Расширение — рабочий инструмент оператора ПВЗ Ozon. Оно НЕ печатает само:
данные отправляются локальной службе printnum-win7.exe (Windows, слушает
127.0.0.1:5000), которая печатает через драйвер Windows.

Без службы интерфейс расширения открывается и настройки сохраняются — можно
проверить popup, вкладки, валидацию полей; запросы к 127.0.0.1 просто вернут
ошибку соединения (обрабатывается, показывается сообщение).

Проверка на живом Ozon требует аккаунта сотрудника ПВЗ, поэтому просим
проверять карточку и функциональность popup.

host_permissions:
• https://turbo-pvz.ozon.ru/* — печать этикеток на странице выдачи Ozon;
• http://127.0.0.1/* — локальная служба печати на компьютере пользователя
  (единственный адрес, никакой внешней передачи данных нет).

Разрешения: storage (настройки, список должников), scripting (инъекция
pageHook в MAIN world страницы Ozon для чтения ответов API о штрихкодах).

Скачать службу: https://github.com/SergeiKabak/cPrintNum/releases
Исходный код: https://github.com/SergeiKabak/cPrintNum
```

## 5. Скриншоты

Требования Edge: PNG/JPEG, минимум 640×480, рекомендуется 1280×800, от 1 до 10
штук, без «водяных знаков» и без чужих логотипов.

Что снять:
1. Popup → «Печать» (поля ячейки, настройки);
2. Popup → «Автопечать»;
3. Popup → «Должники» (список + диагностика);
4. Пример напечатанной этикетки (фото или BMP из `preview/`);
5. Красное предупреждение о должнике на странице выдачи (можно затемнить
   персональные данные).

## 7. Видимость: Public или Hidden

Магазин проверяет «работает ли расширение как заявлено». Без локальной службы
на машине проверяющего оно работать не может, поэтому:

- **Hidden (unlisted)** — ссылка на карточку работает, поиск её не показывает,
  проверка мягче. Рекомендуется для первой публикации.
- **Public** — после 1–3 успешных обновлений и подтверждённой работы.

## 8. Обновления версии

1. Поднять `version` в `package.json` (`2.1.0` → `2.1.1`).
2. `npm run pack:store`.
3. Dashboard → расширение → **Update** → загрузить новый zip →
   в «What's new» написать по-человечески:

```
• Проверка должников: имя клиента в предупреждении.
• Исправлена связка «отправление ↔ клиент» для списков выдачи.
```

## 9. Частые причины отказа

| Причина | Как избежать |
| --- | --- |
| «Не работает» | Notes for certification + описание «нужна локальная служба» |
| Товарный знак в названии | мы убрали «Ozon» из имени; в описании — только как «ПВЗ Ozon» |
| Нет политики конфиденциальности | ссылка на GitHub Pages (проверить, что открывается без логина) |
| Лишние разрешения | у нас только `storage`, `scripting` и два хоста |
| Удалённый код | нет: весь JS внутри архива, `eval` не используется |
| Дубликат | не публиковать ту же версию повторно — поднимать `version` |
