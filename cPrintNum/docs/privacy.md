# Политика конфиденциальности — PrintNum

_Действует для расширения «PrintNum — печать этикеток для ПВЗ» (Microsoft Edge
Add-ons / Chrome Web Store) и локальной службы `printnum-win7.exe`._

## 1. Кто и что делает

PrintNum — инструмент для сотрудников пунктов выдачи заказов Ozon. Расширение
читает открытую страницу `turbo-pvz.ozon.ru` (номера ячеек, штрихкоды, данные
сессии выдачи) и отправляет их **локальной службе** на этом же компьютере
(`http://127.0.0.1:5000`), которая печатает этикетку на подключённом принтере
этикеток.

## 2. Какие данные обрабатываются

| Данные | Зачем | Куда уходит |
| --- | --- | --- |
| Номер ячейки / адрес | текст на этикетке | только в `127.0.0.1` |
| Штрихкод / номер отправления | QR-код, проверка должника | только в `127.0.0.1` |
| `clientId` и имя клиента (сессия выдачи) | предупреждение о неоплаченном заказе | хранится в браузере, наружу не уходит |
| Настройки печати | чтобы не вводить заново | `chrome.storage.local` |

## 3. Чего расширение НЕ делает

- не собирает статистику, не отправляет телеметрию;
- не передаёт данные на сторонние серверы (единственный внешний адрес —
  сам Ozon, страница которого уже открыта);
- не читает другие сайты (доступ ограничен `turbo-pvz.ozon.ru`);
- не запрашивает пароли, номера карт, cookies других сайтов;
- не содержит удалённо загружаемого кода.

## 4. Хранение и удаление

Все данные лежат локально: список должников и настройки — в хранилище
расширения; файлы предпросмотра — в папке пользователя. Удаление расширения
или очистка его данных удаляет всё безвозвратно. Экспорт/импорт списка
должников в JSON делается вручную, файл остаётся у пользователя.

## 5. Передача третьим лицам

Не передаём. Исключений нет.

## 6. Дети

Расширение — рабочий инструмент оператора ПВЗ, не предназначено для детей.
