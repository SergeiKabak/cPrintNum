## 1. Что нужно до начала

| Компонент                                                        | Нужно?              |
| ---------------------------------------------------------------- | ------------------- |
| Windows 7 SP1 x64 / Windows 10 / Windows 11                      | ✅ Да               |
| Принтер (термопринтер или обычный), установленный в Windows      | ✅ Да               |
| Chromium-браузер (Google Chrome, Яндекс Браузер, Microsoft Edge) | ✅ Да               |
| Python, Node.js, WebView2                                        | ❌ **Не нужны**     |

> **Windows 7:** убедитесь, что установлено обновление
> [KB2533623](https://support.microsoft.com/help/2533623) (обычно уже установлено).
> Если приложение не запускается — установите его.

> ℹ️ **macOS и Linux не поддерживаются.** Приложение работает только на Windows.
> Печать реализована через Win32 GDI/Spooler, которых на других ОС нет.
> Сборка под macOS может использоваться только разработчиками для тестов GUI
> и API — печатать с неё нельзя.

## 2. Установите принтер в Windows

Это делается **до** первого запуска PrintNum.

1. Подключите принтер (USB или сеть).
2. Установите драйвер принтера (для термопринтеров — с диска или сайта производителя).
3. Откройте список принтеров:
   - Windows 10/11: **Параметры → Bluetooth и устройства → Принтеры и сканеры**.
   - Windows 7: **Панель управления → Устройства и принтеры**.
4. Убедитесь, что принтер есть в списке и **не** находится в состоянии «Отключён».
5. Откройте **Свойства принтера → Параметры (Preferences)** и **вручную задайте размер
   этикетки**, который будете использовать в PrintNum (например, 30×20 мм).

> ️ **Самая частая проблема:** если размер бумаги в драйвере принтера и в PrintNum
> не совпадают, этикетка напечатается пустой или текст сместится. Размеры должны
> совпадать полностью.

## 3. Запустите приложение

1. Скачайте `printnum.exe` из раздела **Releases** репозитория.
2. Положите файл в удобную папку, например `C:\PrintNum\`.
3. Запустите **двойным кликом**.

Приложение не требует установки — это один portable-файл. Дополнительные
зависимости не нужны: библиотеки времени выполнения уже включены в файл.

---

## 4. Первая настройка в приложении

Откроется окно **«PrintNum — Печать ячеек»**.

1. **Главный экран.** По умолчанию кнопка красная — **«Остановить»**. Это значит,
   приложение запущено и готово печатать.
2. Нажмите **⚙ (шестерёнка)** справа сверху — откроются **Настройки**.
3. Заполните параметры:

   | Параметр               | Что означает                                                              |
   | ---------------------- | ------------------------------------------------------------------------- |
   | **Принтер**            | Выберите ваш принтер. Список обновляется каждые 5 секунд.                 |
   | **Этикетка (mm)**      | Размер этикетки «ширина\*высота». Должен совпадать с драйвером (шаг 2.5). |
   | **Показывать ID**      | Показывать ли вторую часть номера (например `-47`).                       |
   | **Подчёркивание**      | Вместо точки в конце номера — подчёркивание.                              |
   | **Гибридный формат**   | Включить режим с порогом (см. раздел 7).                                  |
   | **Начиная с номера**   | Порог для гибридного формата. Активен, только если включён гибрид.        |

4. Внизу, в нижней панели справа, смотрите индикаторы:
   - **«Принтер НЕДОСТУПЕН»** (красным) — принтер не выбран или offline.
     Проверьте выбор принтера и его состояние.
   - **«РЕЖИМ ЭМУЛЯЦИИ»** (синим) — включён dry-run, печать не идёт (раздел 9).

Все настройки сохраняются автоматически.

## 5. Установите браузерное расширение

1. Откройте **Chrome Web Store** и найдите **«PrintNum — Печать Ячеек (Ozon)»**
   (или перейдите по ссылке из основного README).
2. Нажмите **«Установить»** и подтвердите установку.
3. **Перезагрузите все открытые страницы Ozon** (F5).
4. При первой отправке номера ячейки браузер может запросить разрешение на обмен
   данными с **localhost**. Нажмите **«Разрешить»** (Allow). В дальнейшем запрос
   не появится.

---

## 6. Проверьте печать

1. Откройте страницу Ozon, где печатаются номера ячеек.
2. Введите или отсканируйте номер ячейки.
3. Изменение списка номеров на странице вызывает автоматическую отправку в PrintNum
   и печать этикетки.

Если номер не печатается — см. раздел 10.

## 7. Как работает логика этикетки

Понимание логики поможет проверить, что печатается именно то, что нужно.

### Обычный режим

- `123-47` → на этикетке крупно **`123.`**, сверху `-47`
  (вторая часть видна только при включённом «Показывать ID»).
- `250` → крупно **`250.`**, без верхней части.

### Гибридный формат (с порогом «Начиная с номера»)

Пусть порог = `500`.

- Номера **меньше** порога (`123`, `499`…) печатаются как обычно.
- Номера **больше или равны** порогу (`500`, `501`…) печатаются **жирным**
  и с перестановкой: крупно **вторая часть**, сверху **первая часть**:
  - `500-47` → крупно **`47.`**, сверху `500-`.

### КГТ

Номера вида `КГТ-1`, `КГТ-2`, `КГТ-3`… **всегда** считаются сработавшим условием
гибридного формата: печатаются **жирным** с перестановкой, независимо от порога.

### Подчёркивание

Если включено «Подчёркивание», точка в конце не ставится, а текст подчёркивается.

## 8. Где сохраняются данные

```
%APPDATA%\PrintNum\config.json      — настройки приложения
%APPDATA%\PrintNum\previews\        — превью из режима эмуляции (если включён)
```

`%APPDATA%` — это `C:\Users\<Имя>\AppData\Roaming`.

Настройки восстанавливаются автоматически при следующем запуске.

## 9. Режим эмуляции печати (dry-run)

Режим позволяет проверить работу приложения **без принтера**: печать на принтер
не выполняется, вместо этого этикетка рендерится и сохраняется как изображение
и отчёт.

### Включение

```bat
:: через аргумент командной строки
printnum.exe --dry-run

:: или через переменную окружения
set PRINTNUM_DRY_RUN=1
printnum.exe
```

В нижней панели появится индикатор **«РЕЖИМ ЭМУЛЯЦИИ»**.

### Что сохраняется

Для каждого вызова в `%APPDATA%\PrintNum\previews\`:

- `label_<текст>_<время>.bmp` — изображение этикетки (белый фон, реальный шрифт и позиции);
- `label_<текст>_<время>.json` — отчёт с вычисленными параметрами (шрифт, позиции, размеры).

### Проверка через командную строку

Пока приложение запущено, можно дёргать API вручную:

```bat
curl http://127.0.0.1:5000/
curl http://127.0.0.1:5000/status-printer
curl http://127.0.0.1:5000/listPrinters
curl -X POST http://127.0.0.1:5000/print-number ^
  -H "Content-Type: application/json" ^
  -d "{\"text\":\"500-47\"}"
```

Это удобно, чтобы протестировать разные номера (`123-47`, `500-47`, `КГТ-1`)
и увидеть результат в `previews`.

## 10. Если что-то не работает

| Симптом                         | Возможная причина и решение                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------------------------- |
| Номер не печатается             | Приложение не запущено / расширение выключено / страница Ozon не перезагружена / принтер не выбран |
| Этикетка пустая или смещена     | Размер бумаги в драйвере принтера ≠ размер в PrintNum (см. шаг 2.5)                                 |
| «Принтер НЕДОСТУПЕН»            | Принтер offline, нет бумаги, ошибка — или принтер не выбран в настройках                            |
| Браузер не видит приложение     | Порт 5000 занят другим процессом; убедитесь, что `printnum.exe` запущен                            |
| Не запускается на Windows 7     | Установите обновление KB2533623                                                                    |
| Печать в режиме эмуляции        | Отключите dry-run (не задавайте `--dry-run` и `PRINTNUM_DRY_RUN`)                                  |

Проверить, что приложение отвечает, можно так (при запущенном `printnum.exe`):

```bat
curl http://127.0.0.1:5000/
:: ожидаемый ответ: {"status":true}
```

## 11. Чек-лист первого запуска

- [ ] Принтер установлен в Windows и не находится в состоянии offline
- [ ] Размер бумаги в драйвере принтера задан вручную и совпадает с PrintNum
- [ ] `printnum.exe` запущен (кнопка «Остановить» красная)
- [ ] В настройках выбран принтер и размер этикетки
- [ ] В нижней панели нет надписи «Принтер НЕДОСТУПЕН»
- [ ] Браузерное расширение установлено и включено
- [ ] Страницы Ozon перезагружены после установки расширения
- [ ] При первом запросе разрешён доступ к localhost
- [ ] Пробная печать номера ячейки успешна
