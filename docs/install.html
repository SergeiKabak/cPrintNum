Автоматическая установка

  1. Скачайте install.ps1 из последнего релиза.
  2. Правая кнопка → Выполнить с PowerShell.
  3. Скрипт скачает архив, распакует в %LOCALAPPDATA%\PrintNum, запустит службу, откроет chrome://extensions и скопирует путь к папке расширения в буфер.
  4. В открывшемся окне: «Режим разработчика» → «Загрузить распакованное» → вставить путь из буфера.
Права администратора не нужны. Скрипт скачивает только с GitHub, ничего не пишет в реестр и не ставит службу Windows.

Вручную

  1. Скачайте PrintNum-<версия>-windows.zip и распакуйте в любую папку (например, C:\PrintNum).
  2. Запустите printnum-win7.exe — это служба печати, окна нет. Брандмауэр: разрешить для частных сетей.
    Проверка: откройте http://127.0.0.1:5000/ — должен быть ответ службы.
  3. Откройте chrome://extensions (или edge://extensions, opera://extensions).
  4. Включите «Режим разработчика» и нажмите «Загрузить распакованное», выберите папку extension рядом с exe.
  5. Откройте https://turbo-pvz.ozon.ru и обновите вкладку (F5).

Проверка печати

  1. Иконка PrintNum на панели браузера → вкладка «Печать».
  2. Проверьте принтер (кнопка «Обновить»), бумагу 43*25, затем напечатайте тестовую ячейку, например 163-1.
  3. Нет принтера под рукой — включите «Предпросмотр» и укажите папку: этикетки сохранятся в BMP вместо печати.

Обновление

Скачайте новый архив, распакуйте поверх папки установки (конфиг config.json можно сохранить), затем в chrome://extensions нажмите «Обновить» у PrintNum и обязательно перезагрузите вкладку Ozon.
