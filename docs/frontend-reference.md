# Референс React/Tauri фронтенда (архив)

Этот документ фиксирует поведение и структуру прежнего фронтенда (React 19 + TypeScript + Tailwind + Tauri 2),
который был удалён в рамках перехода на **нативный Rust GUI (Slint)** с поддержкой Windows 7 x64.

Цель документа — сохранение функционального паритета: при реализации Slint GUI ориентироваться на это описание.

---

## 1. Общая структура экранов

### 1.1 Загрузочный экран (`Loading`)

Показывается, пока HTTP-сервер (`http://127.0.0.1:5000`) не отвечает (`serverOnline === false`).

- Иконка приложения (SVG, `IconApp`, «коробки/ячейки»).
- Заголовок: **«Печать ячеек»**.
- Строка статуса со спиннером: **«Приложение запускается...»** (пульсация).

### 1.2 Основной каркас (`Layout`)

```
┌──────────────────────────────────────────────────────┐
│ [icon] Печать ячеек      [⚙ настройки] [—] [✕]        │  ← header (drag region)
├──────────────────────────────────────────────────────┤
│                                                      │
│             Home  ⇄  Settings                        │  ← main
│                                                      │
├──────────────────────────────────────────────────────┤
│ [github] [telegram]      [обновление]   Принтер НЕДОСТУПЕН│ ← footer
└──────────────────────────────────────────────────────┘
```

**Header:**
- Слева: иконка приложения + текст «Печать ячеек».
- Справа:
  - Кнопка настроек (шестерёнка). При открытых настройках — активное состояние
    (accent-фон), иконка поворачивается на 45°. Переключает `tab`.
  - Кнопка «Свернуть» (`minimize`).
  - Кнопка «Закрыть» (`close`), при наведении — красный фон.
- Header — область перетаскивания окна (в Slint: `TouchArea` + перетаскивание, либо системное окно с рамкой).

**Main:** `tab ? Settings : Home`.

**Footer:**
- Слева — кнопки-«таблетки» с раскрытием при наведении:
  - GitHub → открывает `https://github.com/kirill18734/PrintNum`. Текст: «Документация / Исходный код».
  - Telegram-канал `printnum` → кнопка копирования имени канала в буфер (иконка копирования → галочка на 2 секунды).
- По центру — блок обновления (в новой версии **вне рамок**, можно не реализовывать):
  - «Доступно обновление» + кнопка «Обновить» → «Установка...» / «Обновляется».
- Справа — если принтер offline: **«Принтер НЕДОСТУПЕН»** (красный).

### 1.3 Главная страница (`Home`)

- Большая круглая кнопка 140×140 (w-35 h-35):
  - `running === true` → красная, иконка «стоп», текст **«Остановить»**.
  - `running === false` → зелёная, иконка «play», текст **«Запустить»**.
- Под кнопкой: описание состояния — «Приложение запущено» / «Приложение остановлено»,
  при `running` — анимированные точки (пульсация).

### 1.4 Настройки (`Settings`)

Сверху вниз:

1. Синий текст **«OZON»** по центру.
2. Ряд: **Принтер** + **Этикетка (mm)**.
   - Принтер: выпадающий список из `listPrinters` (обновляется раз в 5 сек), placeholder «Выберете принтер».
   - Этикетка: выпадающий список фиксированных размеров, placeholder «Выберете этикетку».
     Список: `30*20, 40*30, 43*25, 50*70, 58*40, 60*40, 75*120, 100*150`.
3. Разделитель.
4. **«Оформление этикетки»** — блок настроек + превью:
   - Чекбоксы: **«Показывать ID»**, **«Подчёркивание»**, **«Гибридный формат»**.
   - Если «Гибридный формат» включён — поле **«Начиная с номера»** с кнопками `−` / `+`
     (целое ≥ 1, ввод числа, при потере фокуса нормализуется к ≥ 1).
   - Превью (см. 1.5).
5. Разделитель.
6. Ряд: **Тема** + **Стиль темы** (в новой версии — только одна тёмная тема).
7. Внизу по центру: `v{version}`.

### 1.5 Превью этикетки (`PreviewPaper`)

Две «этикетки» (белые карточки, шрифт Arial):

- Левая — для номеров `< expand`:
  - подпись «Этикетки 1 – {expand-1}» (только при `hybrid`).
  - если `idNum`: сверху справа маленький текст `−47`.
  - по центру крупно `123` (при `endLine=false` → `123.`), обычный вес.
- Правая — только при `hybrid`, для номеров `≥ expand`:
  - подпись «Этикетки от {expand}».
  - сверху слева `{expand}−`.
  - по центру крупно `123` **жирным** (с точкой/подчёркиванием по настройкам).

## 2. Состояние и хранение

Все настройки сохраняются через Tauri Store в файл `config.json`
(на Windows фактически `%APPDATA%\PrintNum\config.json`, ключи совместимы с backend).

| Ключ         | Тип       | Значение по умолчанию | Описание                         |
| ------------ | --------- | --------------------- | -------------------------------- |
| `printer`    | string    | `""`                  | Имя принтера                     |
| `paper`      | string    | `"30*20"`             | Размер этикетки «Ширина*Высота» мм|
| `idNum`      | boolean   | `false`               | Показывать ID                    |
| `endLine`    | boolean   | `false`               | Подчёркивание вместо точки       |
| `hybrid`     | boolean   | `false`               | Гибридный формат                 |
| `expand`     | number    | `500`                 | Порог «Начиная с номера»         |
| `running`    | boolean   | `true`                | Приложение активно (печатает)    |
| `theme`      | string    | `"system"`            | Тема (в новой версии не нужна)   |
| `themeStyle` | string    | `"vercel"`            | Стиль темы (в новой версии не нужен) |

Дополнительно backend читает `printerOnline` (не сохраняется) и `listPrinters` (динамически).

> **Важно:** в новой Rust-версии config.json пишется напрямую Rust-кодом в
> `%APPDATA%\PrintNum\config.json`, формат ключей **не меняется** — совместимость
> с уже установленными конфигами сохраняется.

## 3. Работа с backend (HTTP API, порт 5000)

Базовый адрес: `http://127.0.0.1:5000`.

| Метод  | Путь              | Ответ / тело                                                       |
| ------ | ----------------- | ------------------------------------------------------------------ |
| `GET`  | `/`               | `{"status": true}`                                                  |
| `GET`  | `/status-printer` | `{"printerOnline": bool}` (опрос раз в 1 сек)                       |
| `GET`  | `/listPrinters`   | `{"listPrinters": ["Printer A", ...]}` (опрос раз в 5 сек)          |
| `POST` | `/print-number`   | тело `{"text": "<номер>"}` → `"OK"`                                 |

Логика `POST /print-number` (backend):

```
text = body.text.trim()
config = load_config()
if text and config.running and config.printer and printerOnline:
    print_text(text)
return "OK"
```

Backend завершается сам через 10 секунд без запросов (watchdog).
Клиент опрашивает `/status-printer` каждую секунду, поэтому watchdog не срабатывает при открытом окне.

Жизненный цикл backend в старой версии:
- Frontend запускал sidecar `backend.exe` через `shell:allow-execute` (powershell
  `Start-Process ... -WindowStyle Hidden`) при монтировании `AppProvider`.
- При закрытии окна и при установке обновления frontend выполнял `stop_backend`
  (powershell `Stop-Process -Name backend`).

> В новой Rust-версии HTTP-сервер живёт в самом процессе приложения — запуск/остановка
> внешнего процесса не требуется.

## 4. Логика печати (перенесена в Rust 1:1)

См. `backend/print_text.py` (удалён) и `src-printnum/src/print.rs` (новая реализация).

Краткая спецификация:

1. `text` разбивается по `-`: `main` = часть 0, `header` = часть 1.
2. `is_numeric = main.isdigit()`; `main_val = int(main)` если число, иначе 0.
3. `is_kgt = main.upper() == "КГТ" and header.isdigit()`.
4. `is_bold = (hybrid and is_numeric and main_val >= expand) or is_kgt`.
5. `is_swapped = is_bold`.
6. Если swapped: `header_text = main`, `main_text = header`, `force_left_header = true`, `show_header = true`.
   Иначе: `main_text = main`, `show_header = header непусто and idNum`, `header_text = header or ""`.
7. Дефисы у header: `force_left_header ? "{header}-" : "-{header}"`.
8. `endLine ? is_underlined = true : main_text += "."`.
9. Размеры: `width_px = mm/25.4 * dpi_x`, `height_px = mm/25.4 * dpi_y`,
   margin = 5% от соответствующей стороны, `max_allowed_w = width_px - 2*margin_x`.
10. Header: шрифт Arial высотой `height_px * 0.20`, обычный вес; позиция:
    `force_left ? margin_x : width_px - text_w - margin_x`, Y = `margin_y`.
11. Main: подбор высоты шрифта в цикле (старт 10, рост пока влезает по ширине/высоте,
    при превышении −1 и выход); вес `FW_BOLD` при `is_bold`, `underline` при `is_underlined`;
    центрирование по X и Y в оставшейся области.
12. Перед печатью — очистка очереди принтера (`PRINTER_CONTROL_PURGE`).
13. `SetBkMode(TRANSPARENT)`, `StartDoc("Ячейка: {text}")`, `StartPage`, ..., `EndPage`, `EndDoc`.

## 5. Соответствие компонентов (React → Slint)

| React-компонент / файл              | Назначение                          | Rust/Slint                     |
| ----------------------------------- | ----------------------------------- | ------------------------------ |
| `context/AppProvider.tsx`           | статус сервера/принтера, версия     | `state.rs` + таймеры в `gui.slint` |
| `context/SettingsProvider.tsx`      | настройки, список принтеров         | `config.rs` + `printer.rs`     |
| `context/RunningProvider.tsx`       | `running`                           | поле конфига `running`         |
| `context/ThemeProvider.tsx`         | тема                                | не переносится (одна тёмная)   |
| `context/ThemeStyleProvider.tsx`    | стиль темы                          | не переносится                 |
| `pages/loading.tsx`                 | экран загрузки                      | `gui.slint` (состояние)        |
| `pages/home.tsx`                    | главная кнопка                      | `gui.slint`                    |
| `pages/settings.tsx`                | настройки                           | `gui.slint`                    |
| `components/printer.tsx`            | выбор принтера                      | `gui.slint` + `printer.rs`     |
| `components/paper.tsx`              | выбор размера этикетки              | `gui.slint`                    |
| `components/showPaper.tsx`          | блок оформления                     | `gui.slint`                    |
| `components/settingsPaper.tsx`      | чекбоксы + expand                   | `gui.slint`                    |
| `components/previewPaper.tsx`       | превью этикетки                     | `gui.slint`                    |
| `services/api.ts`                   | HTTP-клиент (для extension совместимости — контракт тот же) | `server.rs` (сервер) |
| `services/updater.ts`               | автообновление                      | вне рамок                      |
| `layout.tsx`                        | каркас окна                         | `gui.slint`                    |
